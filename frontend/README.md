# フロント設計書

調弦の候補3案と、箏の楽譜（縦譜）を表示する画面です。プロジェクト全体の概要は [リポジトリのREADME](../README.md) を見てください。

**フロントの役割**：APIから返ってきたJSONを、並んでいる通りに描くこと。楽譜の解析や調弦の計算はすべてバックエンドで行います。

## 画面

**アップロード**
- MusicXML（`.musicxml` / `.xml`）を選ぶとAPIに送る（当面は `sample.json` を読む）
- 送信中は「解析中」などを表示。エラーのときはメッセージを表示

**調弦の候補3案**
- カードに表示：`label`、`description`、`tuning`（13本の音名）、`changedStrings`（変える弦の本数）、`oshiCount`（押し手の回数）
- 最初は B（バランス）を選んだ状態にする。B がないときは1件目を選ぶ
- 案は1〜3件（同じ調弦の案はバックエンドで1つにまとめるため）。件数を3と決めつけない

**縦譜**
- 選ばれた案の `measures` を、下の「縦譜の描き方」の通りに描く
- 調弦を切り替えると縦譜も切り替わる（APIは呼び直さず、受け取ったJSONの中で切り替える）
- 印刷ボタン（縦譜だけを印刷）

**画面サイズ**：PC前提。余裕があれば、スマホでカードが縦に並ぶ・縦譜が横スクロールで見られる程度に対応

## API

- `POST http://localhost:8000/api/analyze`：MusicXMLを `multipart/form-data` で送る（フィールド名は `file` の予定）。下のJSONが返る
- `GET http://localhost:8000/api/health`：動作確認用
- http://localhost:8000/docs でAPIを試せる

フロントを開くアドレスとポート（例：Live Serverなら `http://127.0.0.1:5500`）が決まったら教えてください。バックエンドでCORSの許可に追加します。

## JSONの形

```json
{
  "title": "さくらさくら",
  "composer": "日本古謡",
  "tempo": 80,
  "time": { "beats": 4, "beatType": 4 },
  "candidates": [
    {
      "id": "B",
      "label": "バランス",
      "description": "平調子（一＝E）より六を全音上げる",
      "changedStrings": 1,
      "oshiCount": 1,
      "tuning": ["E","A","B","C","E","G","A","B","C","E","F","A","B"],
      "measures": [
        [ [ {"string":"七"} ], [ {"string":"七","repeat":true} ], [ {"string":"八"} ], [ {"rest":true} ] ],
        [ [ {"string":"七"} ], [ {"string":"八"}, {"string":"七"} ], [ {"string":"九","oshi":"ヲ"} ], [ {"rest":true} ] ]
      ]
    }
  ]
}
```

| 項目 | 意味 |
|---|---|
| `title` / `composer` / `tempo` / `time` | 曲名、作曲者、テンポ（♩=いくつ）、拍子 |
| `candidates` | 調弦の候補（A そのまま／B バランス／C 押し手ゼロ）。1〜3件。同じ調弦の案はまとめて先の1つだけ（例：B と C が同じなら A と B だけ）。平調子で弾けない曲は A がない。C は押し手0にできない曲では `label` が「押し手最少」になる（`oshiCount` が1以上）ので、ラベルは固定せず `label` をそのまま表示する |
| `description` | 調弦の説明文 |
| `changedStrings` | 平調子から変える弦の本数 |
| `oshiCount` | 押し手の回数 |
| `tuning` | 一〜巾の13本それぞれの音名 |
| `measures` | 小節のリスト → 拍のリスト → 音のリスト の3段 |

| JSON | 楽譜に書くもの |
|---|---|
| `{"string":"七"}` | 七 |
| `{"string":"九","oshi":"ヲ"}` | ヲ九（弱押し） |
| `{"string":"九","oshi":"オ"}` | オ九（強押し） |
| `{"string":"七","repeat":true}` | 、（前の音の繰り返し） |
| `{"rest":true}` | ⊙（1拍ぶんの休符・伸ばし。続くときは ⊙⊙ と1マスずつ書く） |
| `{"rest":true,"short":true}` | △（1拍より短い休符・伸ばし。マスの中で音と一緒に並ぶ。例：`[{"rest":true,"short":true},{"string":"八"}]` → △八） |

## 縦譜の描き方

参考の楽譜の画像はDiscordで別に送っていますので見ていただきたいです。

- 箏の弦は13本。奥から 一 二 三 四 五 六 七 八 九 十 斗 為 巾
- **右の列から左へ**、各列は**上から下へ**読む
- 1マス＝1拍。太線が小節の区切り
- 弦ごとのレーンには分けず、1マスに弦名を書く
- 1拍に音が2つ以上あるときは、**1マスの中に縦に**並べる（1拍のリストの順に上から）
- 押し手は弦名の**左**に書く（ヲ＝半音上げる、オ＝全音上げる。例：「ヲ九」）
- ⊙＝1拍の休符・伸ばし、△＝1拍より短い休符・伸ばし、「、」＝前の音の繰り返し。指使いの数字は書かない
- 凡例も箏用に（⊙＝休符・伸ばし、△＝短い休符・伸ばし、、＝繰り返し、ヲ＝弱押し、オ＝強押し）
- **右端の縦書き部分**：タイトル、作曲者、テンポ、拍子、調弦（一〜巾と音名を縦に13行）、調弦の説明文
- 一列四小節
