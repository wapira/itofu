【和楽譜・縦譜変換器】フロントエンド一式

■ 同梱ファイル
1. index.html : 画面構造（序の章：アップロード / 破の章：調弦3案比較 / 急の章：縦譜表示・印刷）
2. style.css  : 現代和モダンデザイン（和紙背景・七宝文様・金箔枠・縦書きレイアウト・印刷用CSS）
3. app.js     : MusicXML解析（DOMParser）・調弦3案の自動算出・縦譜レンダリング処理

■ 使い方
- 3つのファイルを同じフォルダに置いたまま `index.html` をブラウザ（Chrome / Edge / Safari / Firefox）で開くだけで動作します。
- サーバーやインターネット通信は不要です。
